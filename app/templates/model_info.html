Model Used

YOLOv11

The proposed system uses the YOLOv11 deep learning architecture to detect camouflaged military objects in complex environments. The input image first undergoes pre-processing steps such as resizing, normalization, and RGB conversion before being passed to the neural network. The backbone network based on CSPNet extracts spatial features from the image. The PAN/FPN neck combines multi-scale features to improve detection of small or distant objects. The detection head then predicts bounding boxes, object classes, and confidence scores. Finally, Non-Maximum Suppression (NMS) removes duplicate detections to produce the final output. The detected objects are displayed in the Flask web interface with bounding boxes around them.

Dataset Information

The model is trained using a custom dataset specifically designed for detecting camouflaged military soldiers and objects. The dataset contains images collected from multiple environments including forests, deserts, and natural landscapes where camouflage is commonly used. Each image is annotated using the YOLO format with bounding box coordinates and class labels. The dataset includes variations in lighting conditions, object sizes, and backgrounds to improve the robustness of the detection system. The dataset is divided into training and validation sets to evaluate model performance during training and ensure accurate detection in real-world scenarios.
